## 5. 강의 슬롯3 — 이론에서 실습으로 자연스러운 연결 (80분)

> **서사 구조**: 공격을 알았다(슬롯1+2) → 방어를 배운다 → "방어가 효과적인지 어떻게 증명하나?" → 자동화 검증 도구가 필요하다 → promptfoo

```
[1부: 방어 대책] 25분
  - LLM 공격(슬롯1+2)에 대응하는 방어 레이어
  - 입력 검증, 출력 필터, 권한 최소화, 모니터링
  - OWASP LLM Top 10 대응책 (M코드 매핑)

[2부: 자동화 검증의 필요성] 10분
  - "방어를 만들었다 — 근데 실제로 막히는지 어떻게 아나?"
  - 수동 테스트의 한계: 느리고, 빠뜨리고, 재현이 안 됨
  - → 자동화 보안 검증 도구가 필요한 이유

[3부: promptfoo 소개] 30분
  - promptfoo란: YAML로 LLM 보안 테스트를 자동화하는 도구
  - 구조 설명: Provider(타겟 LLM) → Test Cases → Assertions
  - eval 모드: 직접 작성한 테스트 케이스 실행
  - redteam 모드: LLM이 공격 페이로드를 자동 생성
  - 라이브 데모: YAML 파일 열어서 구조 설명 → 실행 → 웹 리포트
  - "이제 여러분이 직접 실행해봅니다" → 실습으로 자연 전환

[4부: LiteLLM proxy + 실습 안내] 15분
  - proxy 연결 방법 (IP 주소, 포트 안내)
  - 연결 확인 방법
  - 트러블슈팅 포인트 미리 공지
```

## 6. ws02 실습 구조

```
nb01 — LiteLLM proxy 연결 확인      (20분) [슬롯4 앞부분]

  Step 0. 강사 proxy IP 설정
          LITELLM_BASE_URL = "http://[강사IP]:4000/v1"
  Step 1. OpenAI 호환 클라이언트로 연결 테스트
  Step 2. 간단한 API 호출 확인 ("한 문장 자기소개")
  Step 3. 연결 체크리스트 (IP 오류 / 포트 오류 / key 오류 구분)

nb02 — Gandalf CTF                  (60분) [슬롯4 후반]
  ※ 브라우저 실습 (gandalf.lakera.ai) + 노트북은 가이드/워크시트 역할

  Step 0.  접속 + 레벨 구조 안내
  Step 1.  Level 1~3: 워밍업 (힌트 + 각 레벨 클리어 포인트)
  Step 2.  Level 4~5: 핵심 챌린지 (전략 힌트 3가지)
  Step 3.  토론: "왜 이 방어가 뚫렸는가?" → T08 이론 연결
  Step 4.  코드 재현: Python으로 동일 프롬프트 인젝션 시도해보기
           (LiteLLM proxy 타겟, nb01 환경 재사용)
  목표: Level 4 이상 클리어

nb03 — promptfoo 자동화 스캐닝      (80분) [슬롯5 전체]
  ※ 슬롯3 강의에서 본 YAML 구조를 직접 실행

  Step 0.  Node.js + promptfoo 설치 (강의에서 이미 설명 완료)
  Step 1.  eval 모드: 강의에서 본 YAML 파일 그대로 실행
           → 수동 테스트 케이스 5개 PASS/FAIL 확인
  Step 2.  YAML 수정 미션: assertion 타입 바꾸기, 테스트 케이스 추가
  Step 3.  redteam 모드: 자동 공격 생성 (numTests=3, 플러그인 2개)
           → 웹 리포트 확인
  Step 4.  wrap-up: "내가 만든 방어가 얼마나 버텼나?" 정리

총                                   160분 (2시간 40분)
  nb01 20분 + nb02 60분 + nb03 80분
```

## 7. promptfoo 선택 근거

garak 대비 ws02 맥락에서 적합한 이유:

| | garak | promptfoo |
|---|---|---|
| 설치 | pip (Python 필수, ws01에서 오류 多) | npx (Node.js, 단순) |
| 설정 | CLI + Python 코드 | YAML 파일 |
| 결과 리포트 | JSONL (읽기 어려움) | 웹 UI 자동 생성 |
| 비코더 친화성 | 낮음 | 높음 |
| 강의→실습 연결 | 어색 | YAML 구조를 강의에서 미리 보고 실습 진행 |

→ **강의 슬롯3에서 YAML 구조를 설명하고 실습에서 바로 사용** — 이론-실습 연결이 자연스러움
