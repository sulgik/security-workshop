Step 2

Gandalf CTF
접속 확인

Gandalf CTF는 브라우저만으로 즐기는 프롬프트 인젝션 보안 게임입니다. 별도 설치 없이 사이트에 접속하면 됩니다.

접속 주소
gandalf.lakera.ai
ℹ 게임 화면(레벨 선택)이 보이면 접속 성공입니다. 사전에 Level 1만 시도해보면 더 좋습니다.
레벨 구조 미리 보기
Level 1–2 방어 없음 — 직접 물어보기
Level 3–4 필터 등장 — 우회 전략 필요
Level 5+ 고급 방어 — 도전 목표
접속 안 될 때 확인 사항
1. 기관 방화벽 → IT 담당자에게 허용 요청
2. 개인 핫스팟으로 접속 테스트
3. 안 되면 강사에게 사전 문의
